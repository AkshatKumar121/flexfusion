# Food catalogue asset

Place the downloaded `flexfusion_food_catalog_v1.json` in this directory.

Expected path:

`assets/data/flexfusion_food_catalog_v1.json`

The app reads this file once and seeds the built-in food records into SQLite. Do not rename the file. See `docs/FOOD_CATALOG_INTEGRATION_ROLLBACK.md` for the import contract and rollback steps.
